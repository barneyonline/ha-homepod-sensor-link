# Icon concepts

Three image-generation concepts for HomePod Sensor Link, generated 8 November 2026 with the built-in image tool. These are original 1254 × 1254 RGBA PNGs with transparency, not active integration branding or accepted Home Assistant brands assets.

| Concept | File | Direction |
|---|---|---|
| 01 · Climate Pod | [Transparent PNG](01-climate-pod.png) | Most direct HomePod + temperature + humidity recognition |
| 02 · Sensor Link | [Transparent PNG](02-sensor-link.png) | Simplest connection-oriented mark; omits an explicit temperature symbol |
| 03 · Climate Home | [Transparent PNG](03-climate-home.png) | Broad smart-home climate identity; busier at small sizes |

[Open the comparison](index.html) or [view the captured preview](light-dark-preview.jpg). The comparison renders the same unmodified PNG on white and charcoal surfaces at 144, 48 and 32 CSS pixels. Navy contours define the shape on light surfaces; pale outer keylines retain it on dark surfaces. Mint/cyan sensor fills and coral temperature accents remain consistent between themes, so separate dark assets are not needed for these concepts.

Recommendation: **01** for immediate product recognition, **02** for a simpler abstract brand. **03** loses more detail at small sizes. Before production use, refine generated edges, adjust optical size/padding and export the selected mark in the required branding dimensions/formats. None replaces existing assets or changes the outstanding upstream branding-acceptance gate.

Full generation briefs are recorded in [PROMPTS.md](PROMPTS.md). No API key, backup, household data or device identifier was used.
